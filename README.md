# Focus Sounds

A calm browser-based soundscape for focus, study and rest. Mix ambient sounds, gentle procedural instruments and a Pomodoro timer in a soft liquid-glass interface.

![Focus Sounds app screenshot](./assets/focus-sounds.png)

## Features

- Ambient brown, pink and white noise, rain, ocean and wind.
- Procedural piano, guitar, flute, kalimba and handpan textures.
- Five pastel color moods with saved theme selection.
- Pomodoro focus timer, master volume and optional local weather.
- No build step and no external audio files required.

## Run locally

Open `index.html` in a modern browser. For the best browser permissions and audio behavior, serve the folder with any local static server.
